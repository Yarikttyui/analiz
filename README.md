# Анализатор Файлов

Современное десктопное приложение для анализа файлов и папок с интуитивным графическим интерфейсом. Быстро сканирует директории, предоставляет детальную статистику и визуализацию данных о файлах.

## Возможности

- **Быстрый анализ** - Сканирование файлов и папок с отображением прогресса в реальном времени
- **Детальная статистика** - Общее количество файлов, суммарный размер и информация о самом большом файле
- **Таблица с результатами** - Сортируемая таблица с типами файлов, размерами и путями
- **Современный UI** - Темная тема с анимациями и адаптивным дизайном
- **Многопоточность** - Асинхронный анализ не блокирует интерфейс

## Быстрый старт

### Требования

- Python 3.8 или выше
- Windows

### Установка

1. **Клонируйте репозиторий**

git clone https://github.com/Yarikttyui/analiz.git
cd analiz


2. **Установите зависимости**

pip install -r requirements.txt


3. **Запустите приложение**

python main.py


## **Использование**

### Основные функции

1. **Выбор папки/файла**
   - Нажмите кнопку "Выбрать папку" или "Выбрать файл"
   - Или введите путь вручную в текстовое поле

2. **Анализ**
   - Нажмите кнопку "Анализировать"
   - Наблюдайте за прогрессом в реальном времени
   - Результаты отобразятся в таблице и статистических карточках

3. **Просмотр результатов**
   - **Карточка "файлы"** - общее количество найденных файлов
   - **Карточка "размер"** - суммарный размер всех файлов
   - **Карточка "макс"** - размер самого большого файла
   - **Таблица** - детальная информация по каждому файлу

4. **Очистка**
   - Нажмите "Очистить" для сброса результатов

## Технические детали

### Архитектура
- **Многопоточность**: QThread для асинхронного анализа
- **Сигналы**: PyQt6 signals для коммуникации между потоками

### Ключевые компоненты

#### FileAnalyzer (src/core/analyzer.py)
Основной класс для анализа файлов:
- Наследуется от `QThread` для асинхронной работы
- Сканирует папки рекурсивно
- Эмитирует сигналы о прогрессе и результатах
- Поддерживает отмену операции

#### MainWindow (src/ui/main_window.py)
Главное окно приложения:
- Управляет UI компонентами
- Обрабатывает пользовательский ввод
- Отображает результаты анализа
- Обновляет статистику в реальном времени
